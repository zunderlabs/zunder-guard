# Public hosted delivery integration

Prepared source only. The shared workflow now joins exact private artifact admission to the public-authored Pages, Worker and issuer destination adapters. It performs no private checkout, import, npm install or build hook with publication authority. The previously frozen admission foundation's verify-only description records its earlier scope; this integration supersedes that workflow source after its own independent review.

Cloudflare and issuer run in separate jobs, under their exact target public environment and a shared per-target non-cancelling concurrency group. Only the issuer job requests OIDC write. Trusted public tooling and fixture checks run before credential acquisition. The Pages tools lock contains one MIT dependency, installed with lifecycle scripts disabled. Full release verification tools come from the current trusted public source and pinned installers. Provider grants belong only to their publication steps, never the private producer.

Cloudflare verification acquires the exact artifact and validates destination policy. Website verification also runs the full current signed source/assets/SLSA/OCI/native/channel release gate. Publication acquires it again and rechecks API metadata, latest attempt, current public main and identical bytes immediately before a mutation. Private files are held only in memory or fresh private temporary directories; provider adapters remove their staging directory. They do not enter public artifacts, caches or application logs. Preview and staging smoke require the scoped Access service token; production receives no Access headers.

Issuer verification acquires a sealed ZIP without AWS authority. Publication obtains temporary OIDC credentials for the fixed existing account and region, then acquires the current artifact again into a separate fresh runner-private directory. A separate AWS operation step invokes only public controller code, checks the admitted ZIP inventory and uploads those bytes to the existing Lambda. That step receives no private reader token. Always-cleanup removes both data directories. Routine publication never auto-resumes a previously paused issuer; failed/uncertain changes require read-only reconciliation. Health may deliver existing paid orders; it is not new purchase proof.

Still required before applying: effective protected public main/no-bypass and branch-main environment boundaries, the dedicated private artifact reader App, reviewed target policies and real admission records, narrowly scoped destination grants, the actual public issuer OIDC subject/runtime role, and the current full public release verifier with its machine-evidence policy. No candidate identities or provider grants are invented by this source. The private issuer producer is now separately prepared and independently reviewed. This workflow does not provision the ephemeral Testnet purchase backend; that is a separately owned original-context operation. No database migration is performed by the production Worker adapter.

Run the focused public fixture tests and actionlint before integrating. Real hosted execution, applied provider/API observations, complete purchase/email/licence/activation and installation acceptance remain distinct results; this packet alone proves none of them.
