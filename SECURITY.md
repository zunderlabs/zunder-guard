# Security

If you find a way to make Guard do something its documentation says it cannot (exceed your
limits, loosen a stop, resume after a halt or release the kill switch without a person, reach
Hyperliquid with a client key, read the API wallet key, or get a tampered release past
verification), please tell us privately first: hello@zunderlabs.com, subject "security".

Include what you did, what happened and what you expected, the version (`zunder-guard
--version`) and the network (paper, testnet or mainnet), and whether funds are at risk right
now. Never send a private key, seed phrase or API wallet key; we will never ask for one.

We confirm receipt, tell you whether we can reproduce it, fix it in a release and credit you
in the release notes unless you prefer not to be named. Please give us time to ship a fix
before you publish; we agree a date with you.
